## Project Overview

Verdant is a fictional South African retail store specialising in artisan houseplants, handcrafted pots, and natural home accessories. This project is a multi page website built using HTML, CSS, and JavaScript as Part 1 of the WEDE Portfolio of Evidence (PoE).

The website is designed to be fully functional, visually appealing, and easy to navigate meeting the needs of Verdant's target audience: South African consumers interested in sustainable, nature-inspired living.

---

## Website Goals and Objectives

- Showcase Verdant's product range and brand story
- Provide customers with an easy way to browse products and make enquiries
- Build brand credibility through the About Us and testimonials content
- Drive in-store and online traffic via clear calls to action
- Establish an accessible, mobile-responsive, and SEO-friendly web presence

### Key Performance Indicators (KPIs)
- Enquiry form submissions from prospective customers
- Product page views and time-on-site
- Navigation usability across devices and browsers

---

## Key Features and Functionality

- **5 fully linked HTML pages:** Homepage, About Us, Products, Enquiry, Contact
- **Consistent navigation** across all pages with active-state highlighting (via JavaScript)
- **Enquiry form** on `enquiry.html` with front-end validation and a success confirmation
- **Contact form** on `contact.html` with submission feedback
- **Responsive design** using CSS Grid and media queries — works on mobile, tablet, and desktop
- **SEO meta tags** (description, keywords, author) on every page
- **Semantic HTML** using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- **Scroll-triggered fade-in animations** using the Intersection Observer API
- **Two store locations** on the Contact page as required
- **Proper file and folder structure** (see below)
